# Anupama Flooring 🪵🏛️

Anupama Flooring is an international website and export portal for premium surface solutions including Engineered Hardwood, Luxury Stone Polymer Composite (SPC) Vinyl, Glazed Vitrified Porcelain Tiles, Natural Stone / Terrazzo, and Exterior Teak Decking.

## 🎨 Color Theme
- **Royal Navy / Ocean Blue** (`#16385C`, `#102A45`, `#2563EB`)
- **Forest & Emerald Green** (`#1E6F3D`, `#16A34A`, `#10B981`)
- **Warm Teak & Earth Brown** (`#784421`, `#9A5B32`, `#DF9B5B`)
- Clean architectural warm neutrals (`#FBF7F1`, `#FFFFFF`, `#0F172A`)

## 🧭 Navigation Structure
1. **Home** - Hero slider with interactive controls, trust counters, and quick CTA buttons
2. **Company Profile** - Company overview, technical infrastructure, environmental sustainability, and certifications (ISO 9001:2015, CE, FSC, FloorScore)
3. **Products** - Real-time filterable product catalog (Hardwood, SPC Vinyl, Vitrified Tiles, Terrazzo, Decking) with modal spec sheets
4. **Why Choose us** - Core value pillars, AC5 rating, German Unilin® click-lock system, and competitive comparison matrix
5. **Gallery** - Categorized project installations (Residential, Corporate, 5-Star Hospitality, Outdoor Decks)
6. **Contact Us** - Global Request for Quotation (RFQ) form, WhatsApp direct chat, export hotline, and factory address

## ⚡ Key Features
- **Interactive Flooring Area & Cost Calculator**: Dynamic square footage / square meter calculations with wastage buffer and box count estimation.
- **Product Specification Lightbox**: Detailed technical specs, wear layer, size, water resistance rating, and application guides.
- **Export RFQ Dispatch**: Instant reference generation and inquiry confirmation.
- **Fully Responsive**: Optimized across mobile phones, tablets, laptops, and ultra-wide displays.
